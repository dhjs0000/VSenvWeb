功能特性

🗂️

独立实例管理

创建多个独立的 VS Code 实例，每个实例拥有完全隔离的用户数据和扩展目录

🔒

数据隔离保护

每个实例的配置、扩展和项目数据完全独立，避免相互干扰

使用指南

创建新的 VS Code 实例

# 创建默认路径的实例
vsenv create myproject

# 创建指定路径的实例
vsenv create myproject "D:\Projects\myproject"

创建实例后，请将 VS Code 离线包解压到实例目录下的 vscode\ 文件夹中

启动 VS Code 实例

# 基本启动
vsenv start myproject

# 启用沙箱模式
vsenv start myproject --sandbox

# 启用硬件指纹随机化
vsenv start myproject --fake-hw

# 网络隔离启动
vsenv start myproject --proxy http://127.0.0.1:8080

支持多种启动模式，包括沙箱、网络隔离和硬件指纹随机化

管理 VS Code 实例

# 列出所有实例
vsenv list

# 停止实例
vsenv stop myproject

# 删除实例
vsenv remove myproject

# 导出实例
vsenv export myproject backup.vsenv

完整的实例生命周期管理，支持导入导出功能

高级功能

# 注册协议处理
vsenv regist myproject

# 协议守护模式
vsenv regist-guard myproject

# 安装扩展
vsenv extension myproject ms-python.python

# 批量安装扩展
vsenv extension import myproject extensions.txt

支持协议注册、扩展管理和批量操作等高级功能
